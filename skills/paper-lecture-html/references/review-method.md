# 三遍阅读与审阅流程

阅读流程改编自 S. Keshav 的 *How to Read a Paper* §2–3，涵盖 5C 定位、图表支撑的复述和纸上重建。下列前作对照和 HTML 交付要求是本 skill 的应用规则。[论文出处](https://doi.org/10.1145/1273445.1273458)

## 证据与解释的对应规则

从准备到成稿，用“判断 → 来源位置或推导 → 成立条件”的方式核对技术内容。一组论证共用出处时，读者应能分辨这条出处覆盖哪些句子；混合多项来源时按判断拆开。在 `source` 写明作品、版本及实际页码、章节、公式、图表或正式文档条目，已确认的链接用 `citations`。读过摘要只可支撑摘要明确提供的信息。定位信息缺失时使用已核实的最细层级。

| 内容性质 | 要提供的依据 |
|---|---|
| 论文报告的事实、数值或作者给出的理由 | 查目标论文正文、附录、图注和实验设置。写明任务、指标、对照和数据条件。只在作者明说动机时将理由归于作者。 |
| 前作机制、缺点与相对创新 | 用前作原文核实它实际做了什么，用目标论文原文核实改动，用适当的对照或推导判断收益。只有目标论文转述时限于“目标论文如何描述前作”。 |
| 科学背景与已有方法 | 用原始研究、权威教材、综述或适用的标准与官方文档。先用读者能懂的语言复述，再保留支撑定义或机制的位置。 |
| 可复核的推导或再分析 | 标明“由公式推导”“由图近似读取”或类似性质，给出公式来源、前提、关键步骤与精度。机制上的解释有计算依据时可以作为推论；归因到效果须有对应实验或证明。 |
| 类比、重绘与简单算例 | 标明教学用途，交代与原机制的对应、简化和边界。标出哪些数值是为演示选的，所用关系可追到论文或科学依据。 |
| 证据缺失或互相矛盾 | 说清材料是否取得、哪里未报告、判断卡在哪一步。条件不同的结果分别呈现。无法证实的解释写成疑问或省略。 |

导读流程、释义、问答和自测解析同样遵守这套规则。正文中的数据或方法结论也可在附近复用，不要求为相同算例反复附链接。实验图中的差异只在证据允许时解释为统计显著或某个模块造成。

## 第一遍：先知道在读什么

先看标题、摘要、引言、章节标题、结论和参考文献。用 5C 建立初步判断，随阅读更新。

| 要点 | 要回答的问题 |
|---|---|
| Category（类别） | 是理论、方法、系统、实证研究、数据集还是综述？用什么方式评价其贡献？ |
| Context（脉络） | 它解决哪个具体问题，最接近的前作和相关理论是什么？ |
| Correctness（初判） | 关键假设是否合理？是否有需要核对的假设、推理跳步或实验条件？ |
| Contributions（贡献） | 作者提出了什么？哪些贡献有可定位的证据？ |
| Clarity（清晰度） | 哪些定义、术语或实验设置写得清楚？哪些歧义会让读者无法理解或重建方法？ |

把 5C 的结论融入开篇和审阅部分。Correctness 在第一遍只做初判，贡献先记录作者主张。

## 第二遍：让主张对应到前作与证据

为核心主张记录“原文位置、支持证据、比较条件、待核实项”。读图先确认坐标、单位、图例、分组、误差条或区间含义，再比较数值与趋势。无统计检验或足够信息时，用描述性结论。标记重要的未读引用，优先查作者指出的最接近工作、关键方法的原始出处和直接比较的基线。需要补文献时，先从 Related Work 与参考文献追索，再用最接近论文的共同引用缩小搜索范围。

对每个核心问题回答五项，可合并到正文表格或连贯段落。

1. **问题和约束。** 输入、输出、待达目标与适用条件是什么？
2. **前作怎样做。** 讲清实际机制、假设及已解决的部分。前作原文和目标论文对前作的转述分别注明。
3. **缺点在哪里。** 指出局限发生的条件及其后果。若依据只支持“尚未验证”，就写明未验证的范围。缺点若是教学推论，给出推理依据。
4. **本文怎样改。** 说明改动落在哪个表示、模块、目标、训练、数据或评价环节，并沿机制说明如何回应前作局限。
5. **创新与验证。** 指出相对哪项工作、在哪一维度有差异，区分沿用、组合、工程改进与可验证的新贡献。再说明对应证据（如消融、性能对照、复杂度分析或定理）支持到哪一步。

仅在条件足够一致时做直接数值比较。区分历史前作与论文自己的对照基线，核对数据、指标、预算、参数量和实测口径。前作原文未取得时注明依据来自哪里，将判断限定在已有材料。

## 第三遍：按论文假设重建并质疑

- 方法或系统选一条代表性路径，追踪输入形状、中间表示、计算、训练和推理差别、输出与关键超参数。理论论文沿假设、引理、结论与边界走一条证明链。实证论文重建采样、对照、指标与推断过程。
- 用正文公式、伪代码和附录逐步检查。对决定性的计算做维度核对、关键推导或小型代入验算。把原文已报告、可由原文推导和仍需假设的部分标清楚。材料缺失时注明缺什么、影响哪一步。
- 用反例、去除组件或候选方案检验假设，核对实验是否隔离了想要归因的因素。把已确认的局限、合理但未检验的担忧、可验证的后续问题分别说明。
- 在讲稿末尾回到原问题，写明主要贡献、关键依据、最重要的限制以及一个会改变判断的证据或检验。只有实际运行实验后才报告复现运行与结果。
