# 可迁移的教学动作

本文件由重新取得的四个视频、独立转写、选段画面及原论文对照整理。具体时间、版本与复核范围见 [视频证据索引](video-evidence.md)。不使用早期音频分析作为本版依据。

## 两组互补的组织方式

**朱毅相关样本（ViT、ViLT、多模态串讲）**突出比较、计算与可替代设计。先用前作的结构或效果建立问题，解释一个改变为何值得试；用手写形状走通输入；当 `[CLS]`、位置编码等设计引起疑问时立刻跳到附录。串讲会在公布新模型前总结“哪些东西保留、哪些东西改动”，让读者先形成自己的预期。样本依据 T1–T5、L1–L5、M1–M5。

**李沐频道 AlphaFold 2 样本**突出陌生领域的概念桥接和多层结构导航。以机器学习读者熟悉的输入、表示、编码与输出理解生物问题；先看总图，再深入 Evoformer 子图和补充材料伪代码；以索引、几何关系解释新增操作，之后回到总图说明各模块如何协作。样本依据 A1–A5。

这些是有限样本表现出的倾向，不代表两位老师所有视频的固定差异。身份依据与归因强度见证据索引；不按姓名强制分配章节比例。默认按新论文需要组合动作。

## 动作与迁移条件

| 动作 | 应怎样做 | 适用时机 | 易误用处 |
|---|---|---|---|
| 结果带出问题 | 先选最能检验主张的一张图，说明接下来为何要理解方法 | 核心贡献可由一个现象或权衡概括 | 把开场宣传当作已证明结论 |
| 重建前作的比较坐标 | 固定表示、融合位置、目标和成本维度，再定位新方法 | 前作多、名字易混淆 | 按年份堆论文，混淆不同任务的结果 |
| 先让读者预测 | 根据已知局限提出可检验的设计候选，再展示实际设计 | 论文串讲、方法动机 | 假装还原作者真实发现过程；暗示候选唯一 |
| 总图分层导航 | 总览信息流，放大当前模块，解释完回到全图 | 复杂网络与跨领域模型 | 第一次展示总图就讲所有细节 |
| 用输入走一遍 | 写出具体输入和中间形状，解释每个轴的含义 | 表征变换、注意力、拼接、几何操作 | 数值形状碰巧相同就混为同一概念 |
| 设计疑问立即求证 | 把“能不能换一种”带到附录消融，对照相应设置 | 模块必要性与训练细节 | 把论文采用的选择讲成数学必然 |
| 对照伪代码里的改动 | 先复习熟悉算子，仅展开新增偏置、索引、门控等 | 方法建立在标准模块上 | 忽略归一化轴、残差或训练时条件 |
| 类比带边界 | 说明对应的输入、变换与输出，再指出不能对应的部分 | 陌生领域、复杂监督 | 把类比当等式，或借类比声称因果成立 |
| 先建立读图坐标系 | 解释轴、指标、图例、基线范围，再比较一个对照 | 点多、线多的实验图 | 一看到最好点就宣布全面优越 |
| 区分成本层级 | 明确模块、端到端推理、预训练、调参和数据成本 | 效率型论文、部署讨论 | 把视觉前端加速倍数当作模型整体加速 |
| 用反例说明约束 | 构造一个能破坏标签或假设的最小变化 | 数据增强、监督一致性 | 将示例当成真实实验或普遍禁止规则 |
| 把未解问题留在原位 | 解释当前证据支持到哪里，随后给出可检验的新问题 | 消融不充分、未来工作 | 用确定口吻填补论文没有提供的解释 |

## 一段讲稿如何展开

选择一个读者真正可能卡住的问题。先告诉读者看图中的哪一部分，再解释发生了什么，必要时插入计算或对照。每一段推进一个认知变化。最后说明这一步对主线的意义。

例如讲 patch embedding 时，可先问“二维图像怎样成为 Transformer 的输入”，沿原图展示切块、展平、线性投影和增加特殊 token。推导一般形状后，再用明确标注的具体配置验算。接着指出模型维度 D 是可选择的，不能因为某配置恰好等于展平 patch 长度，就说线性层没有作用。

例如讲一个新增 loss，先解释没有它时的具体问题，再指出它监督了哪些表示、如何生成目标、是否改变推理流程。最后用对照实验核查其收益，不因为方法名中含有某词便声称已经证明该机制。

## 从视频迁移到 HTML

- 放大、指向和逐次圈画 → `walkthrough` 中同一张图的分步注释，步骤正文与图同步。
- 手写中间形状 → 可渲染的公式与紧邻的形状表，显式区分一般形式和数值例子。
- 跳转到附录 → 在问题旁插入证据摘要，折叠展示完整对照；提供版本、图号与链接。
- 回到总图 → 结束模块时用一句话定位输出和下一个模块，必要时链接回总图。
- 指着实验讲 → 保留原图，并在正文按真实指标和对照解释，不能用装饰示意图替换实验证据。

复用的是教学组织与可检验的推理。少量自然口语即可；密集口头禅、夸张修辞、固定时长比例和十二类标签不会自动带来更清晰的解释。
