# 讲解动作与音频依据

## 样本与复核范围

四份用户提供的 MP3 对应 ViLT、ViT、多模态串讲上篇与 AlphaFold 2，合计约 283 分钟。现有 base 模型转写存在术语与数字误识别。以下规则来自选定时间窗的语义复核，其中每份音频另有一个 30 至 40 秒的 medium 模型重新转写片段。完整的逐句声学复核仍待进一步完成。

时间以音频起点为零。技术内容是讲解样本的内容摘要，后续解释具体论文时应回论文核对。以下表述经过概括。

## 新讲稿的表达节奏

每个难点可以采用以下短循环。

1. 接住一个具体问题，例如某个表示为什么需要增加位置信息。
2. 给一个可行的直观方案，明确它依赖的条件。
3. 用实例、公式或图表展示限制。
4. 解释本文的操作如何应对该限制。
5. 回到总图，说明刚才的输出下一步交给谁。

问题应有具体回答。类比需要对应原概念的对象与关系。语气自然，术语就近释义。篇幅集中在使读者理解关键机制所需的细节。

## 内部动作标签

| 标签 | 含义 |
|---|---|
| H | 问题与意义 |
| G | 现有方案的限制 |
| B | 核心假设与机制 |
| F | 总图和局部读图 |
| S | 符号、形状和假设 |
| N | 基础方案与替代方案 |
| M | 方法计算与设计理由 |
| T | 数值或情境实例 |
| E | 实验和控制变量 |
| C | 证据缺口和适用边界 |
| L | 经核实的前作关系 |
| R | 回扣和复现要点 |

旧标签脚本对未命中内容采用 M 作为默认项，所生成的约 81% 方法占比不能视为语义复核后的风格统计。本 skill 采用有依据的动作和选段，不用该比例分配新讲稿篇幅。
