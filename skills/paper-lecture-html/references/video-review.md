# 从参考视频独立提炼讲法

仅在用户要求研究视频、音频或校准讲解范式时使用。普通论文讲解不需要再次下载本 skill 的参考视频。

## 取得可核对材料

1. 根据用户链接核对标题、视频 ID、分 P、时长、发布信息与公开署名。上传账号与参演名单不必然等于主讲人；需要精确归因时检查本人发布记录或明确介绍。
2. 优先取得可用的平台字幕；没有字幕时，从授权可访问的原视频抽取音频并生成带时间戳的 ASR。用户要求全新提取时不要读取被排除资料及其衍生摘要。
3. 保留获取时间、原链接、媒体与论文哈希、转写模型及参数。不在报告里泄漏会话凭据或临时签名地址。失败时换正常可用的公开来源或说明缺口。
4. 先用全片索引找到背景、结构、公式、实验和回扣，再选择上下文完整的片段。自动转写不是逐秒人工复核。术语、数字、否定句与符号用原论文和关键片段的二次识别核对，无法确认就标记。
5. 对涉及指向、手写、放大或切换的片段提取连续的前后帧。单张截图仅支持该时刻画面，不支持完整动作顺序。与论文原图比较，区分作者已有标色和讲解时新增标注。

## 关联论文

先从画面标题、作者、版本标记、图表和符号确认对应论文。串讲可能覆盖多篇，且展示旧版。分别保存“视频展示版本”和“技术核对版本”；无法对齐的部分不宣称一致。

每个重点用一条记录保留以下字段。

```text
id / video_url / start_s / end_s
observed_teaching_action
reviewed_frames_s / transcript_review_scope
paper_url / paper_version / section_figure_equation
paper_check / correction_or_boundary
transfer_rule / when_to_use
```

将三层结论分开。

- 视频直接呈现了什么讲解动作。
- 原论文支持什么技术事实，哪些说法需要修正或限定。
- 迁移到新论文的建议是什么，这是总结者提出的规则。

## 形成可复用规则

从多个片段找反复出现的动作，并检查有无相反例子。按动作解决的问题组织规则，不根据关键词频次给老师贴风格标签。单例保留为样例；不推算未经完整标注的时间比例。

语音讲解可以先说近似值，讲稿应回到原图标注。教学假设有启发作用，但不能写成作者心理活动。历史排行榜、训练价格、后续成果和“首次”判断必须保留时间范围。

交付语义摘要、时间链接、必要的小范围图像对照和规则。完整媒体、未经校验的 ASR 与临时文件留在工作目录；没有需要就不把它们复制进 skill 或发布给他人。说明完整获取与抽样复核各覆盖多少，记录实际未解决的证据缺口。
